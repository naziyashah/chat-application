# Chat Application

A simple dynamic chat application built using Node.js, Express.js, MongoDB and EJS.

## Features

- Create new chats
- View all chats
- Edit existing messages
- Delete chats
- Delete confirmation popup
- Created and updated timestamps

## Tech Stack

- Node.js
- Express.js
- MongoDB
- Mongoose
- EJS
- HTML
- CSS
- JavaScript

## Installation

1. Clone the repository:

   `git clone https://github.com/naziyashah/chat-application.git`

2. Navigate to the project folder:

   `cd chat-application`

3. Install dependencies:

   `npm install`

4. Start the application:

   `node index.js`

5. Open `http://localhost:3000` in your browser.
